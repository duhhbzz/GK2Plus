# Graveyard Keeper Plus

**GK2+** is a modular quality-of-life and gameplay enhancement suite for **Graveyard Keeper 2**, built on BepInEx and Harmony.

> 🚧 Early Development

GK2+ aims to provide configurable improvements and additional gameplay options while allowing players to enable or disable individual features to suit their preferred experience.

## Status

Initial development has begun. The first release will establish the core plugin framework and initial quality-of-life modules.
