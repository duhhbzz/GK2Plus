## Main Description

# GK2+ — Graveyard Keeper Plus

**One mod, your way.**

GK2+ is a modular, configurable quality-of-life and gameplay enhancement suite for
**Graveyard Keeper 2**.

Instead of installing a pile of small overlapping mods, GK2+ brings a growing set
of gameplay improvements, quality-of-life features, UI upgrades, tracking tools,
storage/inventory enhancements, optional cheats, save-safety systems, and other
convenience features together behind one native-style in-game menu.

Features are designed to be independently configurable where practical, so you can
use the parts you want and turn off anything that overlaps with another mod you
prefer.

## Why GK2+?

- **One configurable suite** instead of many tiny overlapping mods.
- **Native-style UI** designed to feel like it belongs in Graveyard Keeper 2.
- **Compatibility-conscious design** using narrow patches and native game systems.
- **Feature-by-feature control** instead of all-or-nothing behavior.
- **Controller / Steam Deck friendly menu access.**
- **Shared save-safety infrastructure** for features that perform persistent changes.
- **Open source and actively documented.**

GK2+ continues to grow, so this page intentionally does **not** maintain a duplicate
feature list.

## Controls

GK2+ includes an in-game menu that works from both the main menu and active
gameplay.

The default keyboard shortcut is **F2** and can be changed in the GK2+ General
tab. Controller / Steam Deck access is also supported.

For the current control scheme and configuration behavior, see:

**Configuration Guide**  
https://github.com/duhhbzz/GK2Plus/blob/main/docs/CONFIGURATION.md

## Save Safety / Optional Cheats

GK2+ includes shared safety infrastructure for features that perform persistent
mutations. Optional cheat-classified actions use GK2+'s save-safety,
cheat-taint, and achievement-protection systems.

Normal quality-of-life features do not mark a save as cheated simply because
GK2+ is installed.

Exact behavior is documented in the Feature Catalog.

## Compatibility Philosophy

GK2+ prefers:

- narrow Harmony patches;
- Graveyard Keeper 2's native systems;
- independently configurable features;
- minimal interference with unrelated game behavior;
- player choice when another mod provides overlapping functionality.

If another mod provides an implementation you prefer, disable the corresponding
GK2+ feature where supported.
